# Tamay Delivery System

A modular web-based delivery management platform for a company-operated truck fleet.

## Technology

- React and TypeScript
- Vite
- Tailwind CSS
- React Router
- Supabase PostgreSQL, Authentication, Storage, Realtime, and Edge Functions
- Stripe
- Google Places and Routes APIs
- Vercel

## Repository Workflow

- `main`: production-ready code
- `develop`: completed and tested feature integration
- `feature/*`: independently developed modules

See [Branching](docs/BRANCHING.md) before starting feature work.

## Development

```sh
npm install
npm run dev
npm run build
npm run lint
npm run test
```
